# Writing Skill

When the user wants text rewritten, summarized, or formatted, follow these steps:

1. **Identify the goal.** What is the user trying to achieve with this text?
2. **Know the audience.** Internal team, external client, executive, friend?
3. **Keep it concise.** Aim for fewer words, not more. Cut filler.
4. **Use clear structure.** Bullet points for lists, paragraphs for narrative, code blocks for examples.
5. **End with a clear takeaway** — what should the reader do or remember?

Use the `summary(text)` tool with the original text to get a stubbed polished version.
The user will then see the polished output as your final answer.

Always load this skill (via `use_skill('writing')`) BEFORE calling the `summary` tool.
